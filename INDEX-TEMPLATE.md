# Worldview Finder index

You don't need to fill this in. The assistant writes it at the end of each session. It's a short note of where you left off, so you can paste it into a new chat and pick up again. The bracketed fields show what goes where.

- Record updated `[YYYY-MM-DD]`
- Latest session `[S01 · YYYY-MM-DD]`
- Style `[Gentle and curious / Direct and challenging]`
- Mirrors `[about every 3 substantive answers and at the end / custom cadence / off]`
- Order `[scenes first / chapters first / pick as you go]`
- Archive coverage `[full / excerpts only, with dates or entry IDs]`
- Resume `[open question or proposed next ID and topic]`
